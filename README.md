# ADOPTME

Android pet-adoption app (Kotlin, Jetpack Compose, Material 3, MVVM, Room). The interface is Russian.

Open the **`AdoptMe/`** folder in Android Studio and run on an emulator or device (minSdk 26).

See [`AdoptMe/README.md`](AdoptMe/README.md) for installation, the local demonstration administrator, optional Google Maps key, implemented features, and limitations.
